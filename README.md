## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Goelrah/Goelrah.github.io.git
   cd Goelrah.github.io
   ```

2. **Open in browser:**
   ```bash
   # macOS
   open index.html
   
   # Or use a local server
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

## 📄 Adding New Blog Posts

1. Create a new HTML file in the `blog/` directory
2. Use the existing article template structure
3. Add the article link to `index.html`
4. Commit and push to deploy

## 🎨 Customization

### Colors
Edit CSS variables in `assets/css/style.css`:
```css
:root {
    --primary: #667eea;
    --secondary: #764ba2;
    --text: #2d3748;
    --background: #f7fafc;
}
```

### Content
- Update `index.html` for homepage content
- Update `about.html` for personal information
- Add new articles in `blog/` directory
